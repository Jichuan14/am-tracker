# AM Track 2.9.0 Beta 3

For Apple Silicon Macs running macOS 13 or later.

1. **For you:** Refresh now favors songs and albums absent from the previous three batches within seven days, reusing the least recently shown choices when fresh options run out.
2. **Remembered recommendations:** Reopening the app and background updates preserve the current batch, while playback and feedback replace ineligible items.

Download `AM-Track-2.9.0-beta.3-macOS-arm64.zip`, quit AM Track, then unzip the download and replace the old `AM Track.app` in Applications. Your listening data stays in its existing data folder. The matching `.sha256` file contains the ZIP's SHA-256 checksum. GitHub's automatically generated source-code archives require building the app yourself.

This release was built and packaged with tests skipped at the maintainer's request.

This beta is ad hoc signed and is **not notarized by Apple**. If macOS blocks opening it, follow the included installation guide and use **System Settings > Privacy & Security > Open Anyway** for AM Track if you trust the download. See [Apple's instructions](https://support.apple.com/102445).

All listening data and preferences stay on the user's Mac. The download contains no listening database or library export. Music itself may contact Apple for playback.

Queue additions use a private macOS interface and require verified catalog IDs. Compatibility varies by macOS version and track. This beta supports Apple Silicon only, and recording observes playback on the Mac while the app is running and the computer is awake.
